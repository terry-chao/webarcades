# 🕹️ HTML5 Arcade | 网页游戏合集

A growing collection of classic browser games built with pure HTML5 Canvas + Web Audio API.  
No frameworks, no external assets — just open the HTML file and play!

---

## 🎮 Games

| Game | 游戏 | Description | Status |
|------|------|-------------|--------|
| [Tank Battle](tank-battle/) | 坦克大战 | Classic Battle City clone with 5 levels, 4 enemy types, 6 power-ups | ✅ Play |

> More games coming soon…

---

## Features

- **Keyboard + Mouse** controls for every game
- **Procedural graphics** — all sprites drawn with Canvas API (no image files)
- **Synthesised sound effects** — Web Audio API, no audio files needed
- **Self-contained** — each game is a single folder, works offline

---

## Controls (Tank Battle)

| Action | Keys |
|--------|------|
| Move | `WASD` / Arrow keys |
| Shoot | `Space` / `Enter` |
| Aim & shoot | Mouse click (shoots toward cursor) |
| Pause | `P` / `Escape` |
